# Budgeting App

Schoolproject voor een mobile-first budget app voor jongeren en ouders.

## Structuur

- `src/`
  React frontend
- `backend/`
  PHP API basis
- `docs/`
  Korte projectdocumentatie

## Frontend starten

```bash
npm install
npm run dev
```

## Backend basis

De backend staat klaar in `backend/` met een simpele route-structuur voor:

- registratie
- login
- ouder-kind koppeling
- potjes
- transacties
- goedkeuringen
